# EU AI Act Classification Lab

Consulting lab. Classify four client AI use cases against the EU AI Act, review a partner's cases, produce an approval pack, and close out after a client discussion.

## File map

| File | What it actually is | Lab term |
|---|---|---|
| `consulting-usecases.md` | My four client briefs, labels removed. What I sent my partner to classify | Consulting response (hidden briefs) |
| `Consulting-answers.md` | My four client briefs WITH the real category and reasoning. Kept private, not shown to partner until Phase 4 | Private answer key |
| `consulting-response.md` | My review of my partner's four hidden cases. First-pass category, reasoning, architecture, roles, controls, decision | Phase 2 consultant review table |
| `EU AI Act Approval Phase3.md` | The client-facing deliverable. Executive summary, all four cases, decisions, redesign for the prohibited case | Phase 3 approval pack |
| `Phase4 closing note.md` | My calls vs my partner's real answer key, client reaction, closing note | Phase 4 client discussion |

Note on naming: `Consulting-answers.md` is my private answer key, not my review of my partner's cases. `consulting-response.md` is my review of my partner's cases, not my own answer key. The names are similar, this table is the source of truth for which is which.

## Result

All four category calls in Phase 2 matched my partner's intended answer key in Phase 4. No redesign needed after the client discussion.
