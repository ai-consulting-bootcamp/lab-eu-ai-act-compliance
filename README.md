## Lab workflow

1. **Phase 1 — Author:** Draft four realistic client scenarios spanning prohibited, high-risk, transparency and minimal-risk outcomes; retain the intended categories in an answer key.
2. **Phase 2 — Review:** Independently classify Barsha's four briefs and identify architecture, roles, controls and launch decisions.
3. **Phase 3 — Advise:** Write an approval pack with a lawful redesign for the prohibited proposal and conditional controls for other cases.
4. **Phase 4 — Discuss:** Compare the intended and inferred categories, capture partner feedback and document final sign-off.
